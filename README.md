# Energy Consumption of Public Properties in Berlin

This repository contains RDF data and a static site including all URIs in the data within the `https://berlin.github.io/lod-energyconsumption` namespace.

The site was generated using [Jinja-RDF](https://github.com/berlinonline/jinjardf).

The repository was generated from [lod-berlin-template](https://github.com/berlin/lod-berlin-template) using [copier](https://copier.readthedocs.io/).

**[Start browsing the data!](https://berlin.github.io/lod-energyconsumption/)**
